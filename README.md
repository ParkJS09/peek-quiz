# 🔍 구멍 엿보기 퀴즈

이미지의 일부만 구멍으로 보여 주고, 구멍을 하나씩 열면서 무엇인지 맞히는 커뮤니티 이벤트용 게임이에요.

- **운영자** (`admin.html`): 7일 × 하루 2문제를 미리 등록하고, 당일에 공개해요. 참여자 수와 정답자 수를 볼 수 있어요.
- **플레이어** (`index.html`): 닉네임으로 참여해요. 힌트(구멍)를 적게 볼수록 점수가 높고, 랭킹으로 경쟁해요.

## 점수
구멍이 n개인 문제를 힌트 k개를 보고 맞히면 `round(100 × (n − k + 1) / n)`점이에요. 오답은 감점이 없고(1초에 한 번만 제출 가능), 포기하면 0점이에요.

## 구조
- 화면: GitHub Pages(정적 파일)
- 데이터: Supabase(Postgres). 정답 확인, 이미지 제공, 점수 계산은 모두 DB 함수(`supabase/schema.sql`)가 처리해요.
  플레이어는 정답과 아직 열지 않은 힌트 이미지를 받을 수 없어요.

처음 설정하는 방법은 [SETUP.md](SETUP.md)를 보세요.

## 파일
| 파일 | 역할 |
|---|---|
| `index.html`, `player.js` | 플레이어 화면 |
| `admin.html`, `admin.js` | 운영자 화면(문제 등록, 구멍 편집기, 공개 관리) |
| `common.js` | Supabase 호출, 로그인, 이미지 처리 공통 코드 |
| `config.js` | Supabase URL과 공개 키 |
| `supabase/schema.sql` | 테이블, 보안 규칙, 함수 |
| `dev/` | 로컬 테스트용 가짜 서버와 DB 테스트 |
