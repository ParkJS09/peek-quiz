# 🔍 구멍 엿보기 퀴즈

이미지에서 원하는 지점에 구멍을 뚫고, 구멍을 하나씩 열면서 정답을 맞히는 게임이에요.
설치나 빌드 없이 `index.html`을 브라우저로 열면 바로 돼요.

## 사용법

1. **이미지 넣기**: 끌어다 놓거나, 클릭해서 고르거나, Ctrl+V(⌘+V)로 붙여넣어요.
2. **구멍 찍기**
   - 클릭하면 구멍이 생겨요.
   - 드래그로 옮기고, 구멍 위에서 마우스 휠을 굴리면 크기가 바뀌어요. 슬라이더로도 조절할 수 있어요.
   - 선택한 구멍은 Delete 키로 지워요.
   - 번호 순서대로 공개돼요. 목록의 ▲▼로 순서를 바꿀 수 있어요.
3. **정답 입력**: 여러 개면 쉼표로 구분해요(예: `광부 유령, 유령광부`). 띄어쓰기, 대소문자, 문장부호는 무시하고 채점해요.
4. 원하는 방식으로 진행해요.
   - **▶ 플레이**: 화면을 공유하거나 직접 플레이해요. 힌트를 적게 볼수록 점수가 높아요(100점부터 시작).
   - **⬇ 힌트 이미지 저장**: `이름-힌트1.png … 이름-정답.png`를 내려받아요. 게시판이나 디스코드에 하나씩 올려서 댓글로 정답을 받을 때 쓰세요.

## 파일

- `index.html`: 화면 구조
- `styles.css`: 스타일
- `app.js`: 편집기, 게임 진행, 이미지 내보내기
